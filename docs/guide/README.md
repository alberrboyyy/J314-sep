# Le guide du projet — comprendre sep-touchid

Ce guide raconte le projet **en français simple**, pour s'y retrouver sans lire le code.
Il est fait pour être lu tranquillement, même sur téléphone. Un chapitre = un sujet.

Si tu veux les détails techniques bruts (messages, octets, traces), ils sont dans
l'**annexe pour agents** : les autres fichiers de `docs/` (`messages.md`, `journal.md`,
`verification_status.md`, `xart_options.md`, `driver_plan.md`, `sensor_hw.md`, `handoff.md`).
Ce guide, lui, explique ; l'annexe, elle, prouve et détaille.

## Une règle de lecture
Partout dans ce guide, on sépare deux choses :
- ✅ **Prouvé** : confirmé par une expérience (on l'a fait, c'est reproductible).
- 🤔 **Supposé** : une interprétation qui tient debout, mais pas encore testée.

Si ce n'est pas marqué prouvé, c'est que ce n'est pas (encore) sûr.
